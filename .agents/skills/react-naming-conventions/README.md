# React Naming Conventions

Naming conventions for React projects. Covers component names, hook names, file names, and folder organization.

## Rules

| Rule | Impact | Description |
|------|--------|-------------|
| `component-pascal-case` | HIGH | Always use PascalCase for component names |
| `component-descriptive-names` | HIGH | Use meaningful names that explain purpose |
| `component-category-prefix` | MEDIUM | Use prefixes to organize by category |
| `component-no-redundant-prefix` | HIGH | Don't repeat parent folder in component names |
| `file-match-export` | HIGH | File name must match primary export |
| `hook-use-prefix` | MEDIUM | Hooks use `use` prefix, HOCs use `with` prefix |
| `folder-feature-based` | MEDIUM | Organize by feature, avoid single-file directories |
